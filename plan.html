How to use this

Each morning, open this page and find today. The amber row is today; the button at the bottom jumps to it. Do that day's main task (2–3 hours, more at weekends) plus the 30-minute Python line.

Then open the Tracker, click today's square, and log it. This page tells you what to do; the tracker records that you did it.
